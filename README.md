# ネットワークを作ろう！ v0.1

通信インフラ構築シミュレーションゲーム。スマートフォン（iPhone縦画面）優先のUIで、
機器を「買う → 配置する → 線で繋ぐ → 通信テストする」というコアループを遊べます。

## 遊び方（ミッション01）

小さな会社にインターネットを導入するのが目標です。

- PC × 5、スイッチ × 1以上、ルーター × 1 を購入
- すべてオフィスに配置
- PC → スイッチ → ルーター → インターネット の順にケーブルで接続
- 「▶テスト」で通信テストを実行し、5台のPCすべてがインターネットに到達できればクリア

スイッチのポート数が足りない、機器同士の組み合わせが不正、といった問題は
通信テストの結果画面で原因が表示されるので、試行錯誤しながら学べます。

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果をローカルで確認
```

## 技術構成

- Vite + TypeScript（フレームワークなしのシンプル構成）
- 機器・接続・ミッションはすべてデータとして管理（`src/devices.ts`, `src/missions.ts`）
  しているため、将来の機器追加やミッション追加がしやすい構造になっています。

## 実装済み機能（v0.1）

- ショップでの機器購入・所持金管理
- 機器の配置・移動（ケーブルは追従）
- 接続モードでの機器同士の接続（ポート数・接続可能な組み合わせを判定）
- 通信テスト（PCごとにインターネットまでの経路をBFSで判定し、失敗理由を表示）
- ミッションクリア判定・報酬・クリア画面
- ゲームリセット

## v0.1で実装しないもの

IPアドレス、DHCP、DNS、VLAN、ファイアウォールなど、詳細設計書 v0.1 §23 に記載の
高度なネットワーク機能は将来バージョンで追加予定です。
