# ネットワークエンジニア・シミュレーター v4.0

ネットワークエンジニアとして働くシミュレーションゲーム。スマートフォン（iPhone縦画面）優先の
UIで、「依頼を受け、現場を調べ、設計し、機器を購入し、物理配線し、設定し、通信試験し、
障害を調査・修理し、納品する」という一連の仕事の流れを遊べます。

- v1.0：機器を買って配置してケーブルでつなぎ、通信テストするコアループ
- v2.0：ゲーム都合の接続制限を撤廃し、IPアドレス・サブネット・DHCP・NAT・DNSなど
  現実のネットワークの仕組みを導入
- v3.0：ネットワーク構成図ではなく「建物の平面図」をゲーム画面の中心に据え、
  部屋・LANコンセント・パッチパネルを使った物理配線、ケーブルの長さ/切断、電源障害を追加
- v4.0：「ネットワークを作るパズル」から「ネットワークエンジニアとして働く」体験へ。
  依頼（案件）を顧客からの手紙として提示し、現場調査（インスペクト）モードと
  説明ブックを追加

## 遊び方

案件は7件用意されており、達成すると報酬を得て次の案件に進みます
（同じネットワーク・同じ建物を継続して拡張していく形式です）。

ヘッダーの依頼名をタップすると📩依頼内容（顧客名・要件・納期・予算目安）を確認できます。

1. **案件01** — ONU・ルーターを使い、1台のPCをインターネットに接続する
2. **案件02** — 5台のPCを接続する（ルーターのLANポートだけでは足りず、スイッチが必要）
3. **案件03** — PCのIPアドレスを手動設定し、正しく通信できるようにする
4. **案件04** — 突然壊れたPC（ゲートウェイ設定が消える）を診断・復旧する
5. **案件05** — 社内サーバーを設置し、固定IPで正しく接続する
6. **案件06** — 部屋のLANコンセントにPCをつなぎ、パッチパネル経由でスイッチへ配線する
7. **案件07** — 離れた倉庫にPCを設置する（直線配線では100mの上限を超えるため、
   中継スイッチ／パッチパネルを間に設置する必要がある）

「🔍調査」モードでPCやサーバーを選ぶと、物理接続 → 電源 → ケーブル長 → ポート状態 → IP →
サブネット → ゲートウェイ → ルーティング → NAT → DNS → インターネット到達、の
11段階を順番にチェックし、最初に失敗した段階とその理由を表示します（Pingツールも使えます）。
PC・サーバー以外の機器（スイッチ・ルーター・LANコンセントなど）を選ぶと、現場調査として
設置場所・電源状態・各ポートの接続先とケーブル情報を確認できます。
答えを一度に全部見せず、「なぜ繋がらないのか」を自分で突き止めるゲーム体験を狙っています。

「🔌配線」モードでは機器同士をタップしてケーブルを引けるほか、既存のケーブルをタップすると
切断できます。

ヘッダーの📖ボタンから、いつでも説明ブックを開けます。ネットワーク基礎・機器・配線・
ネットワーク設定・トラブル対応のカテゴリごとに、「①これは何？②現実では？③ゲームでは？
④構成例」の4項目で解説しています。多くのページには「🔧この画面で試してみる」ボタンがあり、
タップすると該当の操作モードにすぐ切り替わります。

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果をローカルで確認
```

## 技術構成

- Vite + TypeScript（フレームワークなしのシンプル構成）
- 機器・ポート・接続・部屋・案件・説明ブックはすべてデータとして管理
  （`src/devices.ts`, `src/rooms.ts`, `src/missions.ts`, `src/book.ts`, `src/types.ts`）
  しているため、将来の機器追加・案件追加・複数拠点などの拡張がしやすい構造になっています。
- `src/rules.ts` … 物理層の接続可否（有線ポート同士／無線ポート同士のみ）を判定
- `src/netutils.ts` … IPアドレス計算、L2ドメイン（ルーターを越えないLAN範囲）の特定、
  DHCPアドレスの割り当て、IP重複検出、最短経路探索
- `src/cables.ts` … ケーブル長の計算（マップ座標からメートル換算）と上限判定
- `src/diagnostics.ts` … 11段階の通信診断エンジンとPing機能
- `src/book.ts` … 説明ブックのカテゴリ・ページ内容

## 実装済み機能（v4.0）

- ショップでの機器購入・所持金管理（PC・サーバー・ルーター・スイッチ・ONU・Wi-Fi AP・
  LANコンセント・パッチパネル）
- 建物の平面図（部屋）の表示、機器の配置・移動（ケーブルは追従）
- 配線モードでの機器同士の接続（ゲーム都合の制限なし）と、ケーブルをタップしての切断
- ケーブルの種類・長さ（マップ座標から実距離換算）・上限超過の判定
- ⚙設定画面：ルーターのLAN IP/サブネット/DHCP範囲/NAT、PC・サーバーのDHCP/固定IP設定、
  ルーター・スイッチ・ONU・APの電源ON/OFF
- 🔍調査モード：PC・サーバーは11段階の通信診断＋Pingツール、それ以外の機器は現場調査
  （設置場所・電源・ポートごとの接続先とケーブル情報）
- 📩依頼内容モーダル：顧客名・要件・納期・予算目安を表示
- 📖説明ブック：基礎・機器・配線・設定・トラブル対応のカテゴリ別ページと練習モードへの導線
- 通信テスト・案件進行・報酬・完了画面（配線距離・施工コストを表示）
- 案件04での自動障害発生（ゲートウェイ設定の消失）と復旧確認
- ゲームリセット

## v4.0でまだ実装しないもの（v5以降）

案件ごとの独立した予算上限・複数の現場（建物）の選択・キャリアレベル進行、説明ブックからの
独立した練習用サンドバックス画面、L2/L3スイッチの区別・UPS・LANテスターなどの追加購入品、
壁沿いの配線経路（直線表示のみ）、通信ラックのU単位管理、複数フロア、Wi-Fiの電波範囲表示、
マップのピンチズーム、ネットワーク構成図表示への切替、ランダム障害の自動発生、VLAN、STP、
OSPF/BGP、IPv6、ACL、詳細なFirewall設定、VPN、詳細なポートフォワーディング、TCP/UDPの詳細、
ARP、MACアドレス管理、パケットキャプチャ、本格的なルーティングプロトコルは将来バージョンで
追加予定です。
