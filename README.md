# ネットワークを作ろう！ v2.0

現実準拠ネットワーク構築シミュレーションゲーム。スマートフォン（iPhone縦画面）優先のUIで、
機器を「買う → 配置する → 線で繋ぐ → IP/DHCP/DNSを設定する → 通信テストする → 障害を診断して直す」
というループを遊べます。

v1.0では「PCはルーターに直接つなげない」のようなゲーム都合の制限がありましたが、
v2.0ではそれを撤廃し、現実に可能な物理接続はすべて許可した上で、
IPアドレス・サブネット・デフォルトゲートウェイ・DHCP・NAT・DNSが正しく設定されて
初めて通信が成立する、という現実のネットワークの仕組みをゲームの中心に据えています。

## 遊び方

ミッションは5つ用意されており、達成すると報酬を得て次のミッションに進みます
（同じネットワークを継続して拡張していく形式です）。

1. **ミッション01** — ONU・ルーターを使い、1台のPCをインターネットに接続する
2. **ミッション02** — 5台のPCを接続する（ルーターのLANポートだけでは足りず、スイッチが必要）
3. **ミッション03** — PCのIPアドレスを手動設定し、正しく通信できるようにする
4. **ミッション04** — 突然壊れたPC（ゲートウェイ設定が消える）を診断・復旧する
5. **ミッション05** — 社内サーバーを設置し、固定IPで正しく接続する

「🔍診断」でPCやサーバーを選ぶと、物理接続 → ポート状態 → IP → サブネット →
ゲートウェイ → ルーティング → NAT → DNS → インターネット到達、の9段階を
順番にチェックし、最初に失敗した段階とその理由を表示します（Pingツールも使えます）。
答えを一度に全部見せず、「なぜ繋がらないのか」を自分で突き止めるゲーム体験を狙っています。

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果をローカルで確認
```

## 技術構成

- Vite + TypeScript（フレームワークなしのシンプル構成）
- 機器・ポート・接続・ミッションはすべてデータとして管理
  （`src/devices.ts`, `src/missions.ts`, `src/types.ts`）しているため、
  将来の機器追加・ミッション追加・VLANやIPv6などの拡張がしやすい構造になっています。
- `src/rules.ts` … 物理層の接続可否（有線ポート同士／無線ポート同士のみ）を判定
- `src/netutils.ts` … IPアドレス計算、L2ドメイン（ルーターを越えないLAN範囲）の特定、
  DHCPアドレスの割り当て、IP重複検出
- `src/diagnostics.ts` … 9段階の通信診断エンジンとPing機能

## 実装済み機能（v2.0）

- ショップでの機器購入・所持金管理（PC・サーバー・ルーター・スイッチ・ONU・Wi-Fi AP）
- 機器の配置・移動（ケーブルは追従）
- 接続モードでの機器同士の接続（ゲーム都合の制限なし。ポートの種類・空き容量のみで判定）
- ⚙設定画面：ルーターのLAN IP/サブネット/DHCP範囲/NAT、PC・サーバーのDHCP/固定IP設定
- 🔍診断画面：9段階の通信診断＋Pingツール
- 通信テスト・ミッション進行・報酬・クリア画面
- ミッション04での自動障害発生（ゲートウェイ設定の消失）と復旧確認
- ゲームリセット

## v2.0でまだ実装しないもの（v3以降）

VLAN、STP、OSPF/BGP、IPv6、ACL、詳細なFirewall設定、VPN、詳細なポートフォワーディング、
TCP/UDPの詳細、ARP、MACアドレス管理、パケットキャプチャ、本格的なルーティングプロトコル、
ランダム障害の自動発生（設計書 §22）は将来バージョンで追加予定です。
