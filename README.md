# ネットワークを作ろう！ v3.0

物理ネットワーク施工シミュレーションゲーム。スマートフォン（iPhone縦画面）優先のUIで、
「建物の平面図に機器を配置し、LANケーブルを物理的に配線し、IP/DHCP/DNSを設定して、
通信テスト・障害診断で問題を突き止める」というネットワーク施工の一連の流れを遊べます。

- v1.0：機器を買って配置してケーブルでつなぎ、通信テストするコアループ
- v2.0：ゲーム都合の接続制限を撤廃し、IPアドレス・サブネット・DHCP・NAT・DNSなど
  現実のネットワークの仕組みを導入
- v3.0：ネットワーク構成図ではなく「建物の平面図」をゲーム画面の中心に据え、
  部屋・LANコンセント・パッチパネルを使った物理配線、ケーブルの種類/長さ/切断、
  電源障害を追加

## 遊び方

ミッションは7つ用意されており、達成すると報酬を得て次のミッションに進みます
（同じネットワーク・同じ建物を継続して拡張していく形式です）。

1. **ミッション01** — ONU・ルーターを使い、1台のPCをインターネットに接続する
2. **ミッション02** — 5台のPCを接続する（ルーターのLANポートだけでは足りず、スイッチが必要）
3. **ミッション03** — PCのIPアドレスを手動設定し、正しく通信できるようにする
4. **ミッション04** — 突然壊れたPC（ゲートウェイ設定が消える）を診断・復旧する
5. **ミッション05** — 社内サーバーを設置し、固定IPで正しく接続する
6. **ミッション06** — 部屋のLANコンセントにPCをつなぎ、パッチパネル経由でスイッチへ配線する
7. **ミッション07** — 離れた倉庫にPCを設置する（直線配線では100mの上限を超えるため、
   中継スイッチ／パッチパネルを間に設置する必要がある）

「🔍診断」でPCやサーバーを選ぶと、物理接続 → 電源 → ケーブル長 → ポート状態 → IP →
サブネット → ゲートウェイ → ルーティング → NAT → DNS → インターネット到達、の
11段階を順番にチェックし、最初に失敗した段階とその理由を表示します（Pingツールも使えます）。
答えを一度に全部見せず、「なぜ繋がらないのか」を自分で突き止めるゲーム体験を狙っています。

「🔌配線」モードでは機器同士をタップしてケーブルを引けるほか、既存のケーブルをタップすると
切断できます。

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果をローカルで確認
```

## 技術構成

- Vite + TypeScript（フレームワークなしのシンプル構成）
- 機器・ポート・接続・部屋・ミッションはすべてデータとして管理
  （`src/devices.ts`, `src/rooms.ts`, `src/missions.ts`, `src/types.ts`）しているため、
  将来の機器追加・ミッション追加・複数フロアなどの拡張がしやすい構造になっています。
- `src/rules.ts` … 物理層の接続可否（有線ポート同士／無線ポート同士のみ）を判定
- `src/netutils.ts` … IPアドレス計算、L2ドメイン（ルーターを越えないLAN範囲）の特定、
  DHCPアドレスの割り当て、IP重複検出、最短経路探索
- `src/cables.ts` … ケーブル長の計算（マップ座標からメートル換算）と上限判定
- `src/diagnostics.ts` … 11段階の通信診断エンジンとPing機能

## 実装済み機能（v3.0）

- ショップでの機器購入・所持金管理（PC・サーバー・ルーター・スイッチ・ONU・Wi-Fi AP・
  LANコンセント・パッチパネル）
- 建物の平面図（部屋）の表示、機器の配置・移動（ケーブルは追従）
- 配線モードでの機器同士の接続（ゲーム都合の制限なし）と、ケーブルをタップしての切断
- ケーブルの種類・長さ（マップ座標から実距離換算）・上限超過の判定
- ⚙設定画面：ルーターのLAN IP/サブネット/DHCP範囲/NAT、PC・サーバーのDHCP/固定IP設定、
  ルーター・スイッチ・ONU・APの電源ON/OFF
- 🔍診断画面：11段階の通信診断＋Pingツール
- 通信テスト・ミッション進行・報酬・クリア画面（配線距離・施工コストを表示）
- ミッション04での自動障害発生（ゲートウェイ設定の消失）と復旧確認
- ゲームリセット
